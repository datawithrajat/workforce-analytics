# Workforce Analytics: Understanding Employee Turnover

## Project Overview
This project focuses on analyzing employee behavior, overtime participation, job roles, and workplace factors that may influence employee attrition within an organization.

The analysis is being performed using the IBM HR Analytics Employee Attrition dataset with the objective of uncovering meaningful workforce insights through descriptive analytics, hypothesis generation, statistical testing, and predictive modeling.

---

# Project Objective

The primary objective of this project is to:

- Understand employee overtime patterns
- Identify workforce trends across job roles and departments
- Explore factors potentially influencing employee attrition
- Generate business hypotheses using descriptive analytics
- Validate findings through statistical hypothesis testing
- Build predictive models for attrition analysis

# Current Analysis Progress

## OverTime Analysis Completed
Key findings:
- Approximately 28.3% employees are working overtime
- Research Scientists show the highest overtime participation (~33%)
- Sales-oriented roles also demonstrate high overtime involvement

# Business Questions Generated

- Are employees working overtime more likely to leave the organization?
